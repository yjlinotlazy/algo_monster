# Breadth-First Search

Implement:

```python
def bfs(graph: dict[int, list[int]], start: int) -> list[int]:
    ...
```

## Input

`graph` is an adjacency list.

`start` is the starting node.

## Output

Return the nodes visited by breadth-first traversal starting from `start`.

When multiple neighbors are available, visit them in the order they appear in
the adjacency list.
